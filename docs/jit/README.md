# Jit documents moved

Jit is maintained in its own repository: [chayapats/jit](https://github.com/chayapats/jit).

- [Product discovery baseline](https://github.com/chayapats/jit/blob/main/docs/product/README.md)
- [Jit feature specs](https://github.com/chayapats/jit/blob/main/docs/specs/README.md)
- [Migration and ADR mapping](https://github.com/chayapats/jit/blob/main/docs/migration.md)
- [Schway host contract spec S02](https://github.com/chayapats/schway/issues/393)

Schway owns the execution engine and its public host contract. Jit owns project groups, memory, tasks, durable jobs and channels. Product documents are no longer duplicated here.
